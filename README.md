# Arora Dental Care - Modern Dental Clinic Web Application

A pixel-perfect, production-ready dental clinic web application featuring high-end UI/UX, responsive layouts, interactive online scheduling, Google Maps integration, and comprehensive dental service exploration.

## Features

- **Modern Aesthetic Design**: Precision-crafted UI with custom typography, smooth transitions, and brand identity.
- **Online Appointment Scheduling**: Dedicated standalone booking portal (`/appointment`) with custom digital time clock picker (9:00 AM - 9:00 PM with clinic break validation).
- **Responsive Architecture**: Fully optimized for mobile, tablet, and desktop viewports.
- **SEO & Performance**: JSON-LD Structured Data (DentalClinic), OpenGraph meta tags, HTTP compression, and security headers via Helmet.
- **RESTful API**: Lightweight Node.js Express backend for appointment processing.
- **Barrier-Free & Accessible**: Semantic HTML5 with ARIA labels and skip navigation.

## Tech Stack

- **Backend**: Node.js, Express, Helmet, Compression
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Typography**: Custom fonts (Vintage, IntroScript, Roca, Arimo) and Google Fonts (Fraunces, Caveat, Sacramento)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/iamAryan-lanjewar/dentalclinic3.3.git

# Navigate to project directory
cd dentalclinic3.3

# Install dependencies
npm install

# Start the server
npm start
```

The application will be live at `http://localhost:3000`.
